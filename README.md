# LunarEclipse363

Hello! Here's a quick list of some of my projects that you might find interesting. Some of them are hosted outside of GitHub.

Please see my portfolio website for more detailed descriptions (you will find a link in my CV).

- [**Veloren** - an open-world, open-source role-playing game written in Rust](https://veloren.net/) (previously participated in community moderation, creating documentation, programming, currently mostly handling packaging for Arch Linux)
- [**brother-ql-next** - a userspace, cross-platform driver for Brother's QL-series label printers, written in Python](https://github.com/LunarEclipse363/brother_ql_next) (maintainer, refactored internals, fixed bugs, added API documentation, accepting contributions)
- [**brother-ql-net-emulator** - a tool emulating a networked label printer which can receive jobs and pass them onto a wired label printer, written in Rust](https://gitlab.com/LunarEclipse363/brother-ql-net-emulator)
- [**desec-ddns** - dynamic DNS script using the DeSec API](https://codeberg.org/LunarEclipse/desec-ddns)
- [**MIT Kerberos Container** - a complete MIT Kerberos 5 server stack inside an OCI container, using supervisord](https://gitlab.com/LunarEclipse363/mit-kerberos-container)
- [**oauth1-client** - a feature-complete Rust OAuth 1.0a client library](https://gitlab.com/LunarEclipse363/oauth1-client)
- [**bash-game** - a TUI game of Pentago, written entirely with Bash, using some advanced scripting features](https://gitlab.com/LunarEclipse363/bash-game)
- [**VimRename** - a batch-renaming utility written in Python](https://codeberg.org/LunarEclipse/VimRename)
- [**multipurpose-clock** - an AVR-C hardware project, utilizing various I2C and SPI peripherals to create a device that can show the current time, temperature and relative humidity](https://gitlab.com/LunarEclipse363/multipurpose-clock)
- [**branch-archive-test** - a proof-of-concept of branch archiving using custom refs for Git repositories](https://gitlab.com/LunarEclipse363/branch-archive-test)
- [**sweeperlib** - a learning project written in Rust, featuring a library for handling minesweeper game logic, with full rustdoc documentation](https://gitlab.com/LunarEclipse363/sweeperlib)
- [**radicale-decsync-docker** - an OCI container containing the radicale CalDav/CardDav server with the decsync extension, for synchronizing calendars through a local file synchronized with other devices using syncthing](https://github.com/LunarEclipse363/radicale-decsync-docker)
- [**PDF Table Extractor** - the software part of my Bioinformatics Licentiate thesis, a GUI utility written in Python + GTK for extracting tabular data from PDF files](https://pdftableextractor.lunareclipse.zone/)
- **diy-air-purifier** (unreleased, WIP) - a hardware project, featuring an air purifier box (done), a PCB design (done, PCBs manufactured, not yet assembled), and a larger hardware design for an IoT-capable (WIP) air purifier controllable wirelessly (ZigBee or WiFi, not decided yet)
